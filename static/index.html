🧪 Drug Discovery Assistant

FastAPI + LangChain 에이전트 + RDKit — 화합물 물성, PubChem 조회, PubMed 문헌 검색을 하나의 도구로.

화합물 구조를 SMILES 문자열로 입력하세요. 화합물명만 안다면 "화합물 조회" 탭을 먼저 써보세요.
에이전트가 필요에 따라 화합물 조회·물성 계산·문헌 검색을 스스로 조합해서 답합니다. 응답까지 몇 초 걸릴 수 있어요.
이 페이지는 로컬 FastAPI 서버(uvicorn main:app)가 실행 중일 때만 동작합니다. API 원본 명세는 /docs에서 확인할 수 있습니다.
